# Game Chat

An online chat where you can talk to whoever is online, make your own chats, and challenge people to live multiplayer minigames.

## Features

- **Accounts**: sign up with a username and password. You stay signed in on that browser.
- **Global chat** for everyone, plus **New chat** for your own private or public group chats. You can add people to a chat or leave it.
- **Direct messages**: click anyone's name and press **Message**.
- **🤖 AI helper**: the first entry in your chats list is a private chat with an AI helper. Pick who answers at the top:
  - **🧩 Buddy** (the default) is Game Chat's own small AI. It runs right in your browser, so it's free, works without a server key, and uses no AI usage at all. It knows how to play and win every game in Game Chat (Bloxverse experiences included) and where everything is, and it does maths (`15% of 240`, fractions, `2x + 3 = 11`, primes, times tables, averages, shapes), unit conversions, dates and countdowns (days until Christmas or your birthday), word tools (definitions, synonyms, rhymes, spelling, counting letters), jokes, facts, riddles, stories, poems, gamer names, dice and coin flips, and help writing invites and messages. You can play games with it right in the chat: a trivia quiz, a math quiz, hangman, riddles, word scramble, guess the number (either way round), rock paper scissors and would you rather. It remembers your name, birthday and favorite things (say "my name is…", "what do you remember about me?" or "forget everything"). Its answers often come with quick-reply buttons, and when it doesn't know something it offers **✨ Ask Claude instead**.
  - **✨ Claude** is a much bigger AI from Anthropic. Ask it anything: game tips and strategy, rules, homework, ideas, jokes, quizzes, help writing a message. It uses Claude usage. On the website the server needs an Anthropic API key (see [Turn on the AI helper](#turn-on-the-ai-helper)); on claude.ai it uses each person's own Claude plan, and claude.ai asks them once to allow it. Claude is told about Game Chat and its games and keeps things suitable for all ages.

  Answers appear as they're written; ⏹ stops one part-way, **↻ Try again** asks for a different answer, 📋 copies one, and **🧹 New chat** starts over. Only you can see it, and the conversation, your choice of helper and what Buddy remembers are kept in your browser.
- **🧰 Tools** (button in the top bar; press it again to go back to the chat). Everything you make is kept in your browser:
  - **🌐 HTML previewer**: write HTML, CSS and JavaScript and see the page live as you type (or press ▶ Run / Ctrl+Enter). `console.log` and errors (with line numbers) show under the preview. Start from a template (starter page, bouncing ball, profile card, quiz), switch to a big preview, or download it as a `.html` file. The page runs walled off from the chat, so it can't see your chats or sign-in.
  - **🧮 Calculator**: type or tap. + − × ÷, powers, roots, %, n!, sin/cos/tan (degrees or radians), log, ln, π, e and Ans, with brackets and `2π`-style multiplication. History of your answers; click one to reuse it.
  - **⏱️ Stopwatch** with laps, and a **timer** (quick 30 s – 15 min buttons) that keeps going while you chat and rings when it's done.
  - **🔁 Unit converter**: length, weight, temperature, speed, time, volume, data and area, both ways.
  - **🎲 Random**: roll up to 6 dice (d4–d100), flip a coin, pick a number, or paste names to pick one, shuffle the order or make teams.
  - **📝 Notes**, **✅ To-do list**, **🎨 Colors** (picker, HEX/RGB/HSL to copy, shades, and whether white or black text is readable on it), **🔤 Text tools** (word count, UPPER/lower/Title case, sort, remove repeats, find & replace) and **🔢 Number bases** (decimal, binary, octal, hex, and text ↔ binary).
- **Presence**: see who's online. The "N Online" counter and "active" counts update live, and so does the typing indicator.
- **Settings** (laid out like the mockup):
  - Name, password and username
  - Status: Online, Offline (appear offline), or Idle / do not disturb. While you're on do not disturb, nobody can challenge you.
  - Background: White, Black, or any custom color
  - Profile picture: choose a photo (cropped to a square automatically), or pick a color swatch or use the color picker
  - Sound on/off for @mentions and direct messages
  - Bio, favorite games and friends list
  - Sign out
- **Reactions**: hover a message and press 😊 to react (👍 ❤️ 😂 😮 😢 🔥 🎉 👀). Click a reaction to add yours or take it back.
- **Polls**: press 📊 next to the message box, write a question and 2–6 options. Everyone can vote and change their vote, and the results update live.
- **@mentions**: type `@` to pick someone. Their name is highlighted, and they get a pop-up, a red **@** badge on the chat and a sound.
- **Delete** your own messages (🗑️). Everyone sees "This message was deleted".
- **Search** (🔍 or Ctrl+K) through recent messages, file names and polls in all your chats. Click a result to jump to it.
- **Emoji picker** (😊 next to the message box) and clickable links in messages.
- **Formatting**: `**bold**`, `*italic*`, `~~strike~~`, `` `code` ``, code blocks with three backticks, `> quotes` and `||spoilers||` (click to reveal). The message box is multi-line: Enter sends, Shift+Enter starts a new line.
- **Commands** (type `/` for suggestions): `/me waves`, `/shrug`, `/tableflip`, `/unflip`, `/lenny`, `/roll 2d6`, `/flip`, `/remind 10m stretch` (only you see reminders) and `/help`.
- **Emoji shortcodes**: type `:fire:` (with suggestions after two letters). A message of just a few emoji shows them big.
- **@everyone and @here** ping everyone in the chat.
- **Mention sound**: when someone @mentions you (or edits a message to mention you), or sends you a direct message, while you're on another tab, in another app, in a game, or in another chat, a sound plays. Browsers only allow sound after you've clicked or typed on the page once, so the chat gets sound ready on your first click. Pick Ding, Chime, Bell, Pop, Blip or none, and the volume, in Settings. Mentions still ping in muted chats.
- **Message menu** (⋯ on a message): copy text, forward to another chat, pin to the chat, save for later. Double-click a message to 👍 it.
- **Chat menu** (⋯ in the top bar): pinned messages, saved messages, photos & videos in the chat, export the chat as a text file, favorite (keeps it at the top), mute, mark all chats read, and a list of commands and shortcuts.
- **Drafts** are kept per chat. A **Jump to latest** button shows how many new messages arrived while you were scrolled up, and a **New messages** line marks where you left off. **Alt+↑/↓** switches chats.
- **Custom status** under your name, **friend online alerts**, and **blocking** someone (from their profile) hides their messages, pings, typing and challenges. Blocking, muting, favorites, drafts, saved messages and sound settings are kept in your own browser.
- **🕹️ Games** (next to Request a game): party games with **servers** anyone can join. Make a server (name, how many players, how long to draw) or join one from the list; the host presses Start. For now there's **Draw Phone**, like Gartic Phone: everyone writes a prompt, then the papers go round: you draw the prompt you're handed, the next person describes your drawing, and so on until every paper has visited everyone. Then the host shows each album step by step (or all at once), and can start another game. Drawing has colors, 4 brush sizes, a paint bucket, an eraser, undo (Ctrl+Z) and clear. Each round has a timer; when it runs out, what you have is sent. The **▁ Chat** button takes you back to the chat while the game keeps going. On the website the server runs each game; on claude.ai the host's browser does (if the host leaves, the next player takes over), drawings are stored like shared photos, and a server everyone has left is tidied away after 10 minutes.
- **🎲 Classic games — tables** (in 🕹️ Games): every Request-a-game game except Apex Rush and Tower Defense (which have their own online modes) also has 6 **tables** to join. Pick a game, then **Join a random table** or a specific one. The next players in line play while everyone else at the table watches the match live; afterwards the winner stays on and everyone else goes to the back of the line. **Just watch** takes you out of the line, **Play** puts you back. **Snake, Light Cycles and Tetris Battle seat up to 4 players** at once (the match waits a few seconds longer for more people before it starts); every other game is 1 v 1. A pill at the bottom shows where you are in line. The first person at a table runs its matches in their browser (on both the website and claude.ai); if they leave, the match ends and the next person takes over the table.
- **⛏️ Blockcraft** (in 🕹️ Games): a Minecraft-style building game. Six worlds (servers), each an **endless open world** generated from its own seed; **Join a random world** or pick one. Everyone in a world sees each other (with name tags) and every block anyone places or breaks, live, and can chat (T). Worlds are **saved**: whoever has been in a world longest saves it every few seconds (on the website the chat server keeps it in `data/game-saves/`, on claude.ai it's stored with the page), so builds are still there next time. Controls: WASD move, mouse look (click the game; Esc lets go), Space jump (double-tap or F to fly; Space/Shift up/down), left click break, right click place, 1–9 or the wheel pick a block, E opens all 29 blocks, middle click copies a block, Ctrl sprint, F3 more detail (position, chunks, fps). A 15-minute day/night cycle is the same for everyone.
  - **Open world**: there's no edge (well, a wall 30,000 blocks out). The ground is made in 16×16 chunks as people come near, the same every time and for everyone, and drawn in a circle around you, nearest first; chunks far from every player are forgotten and made again when someone comes back, with everything people changed laid back over them. Out past the first stretch around the spawn come **biomes**: plains and forests, **deserts** with cactuses (they prick in Survival), **snowy taiga** with spruce trees and frozen, slippery **ice**, high **mountains** with snowy peaks, and **seas**; little **cabins** (with a bed, a bookshelf and a light) turn up here and there. The top-left corner shows the biome and your position. In the pause menu, **🏠 Back to spawn** takes you home and **👁️ View** switches the view distance (Near, Normal or Far; on a slow computer it drops to Near by itself, until you pick one). Worlds saved before the world was open load as they were, around the spawn.
  - **Creative or Survival**: pick a mode on the world list (or switch from the pause menu). **Creative** is as above: every block, flying, nothing can hurt you. **Survival** has health and hunger (eat by right-clicking food), fall damage, and mining that takes time: hold the left button, and stone, ores and bricks need a pickaxe (wood → stone → iron → diamond) to drop anything. Blocks you place come out of your inventory. **E** opens your inventory and **crafting** (planks, sticks, pickaxes, swords, bricks, TNT, wool dyes…) and **smelting** with coal (iron and gold ingots, glass, cooked meat). Your inventory, health, food and position are saved per world.
  - **Mobs**: pigs, cows, sheep, **chickens** and **rabbits** (they hop) wander by day (porkchops, beef, wool, mutton, chicken, feathers, rabbit). **Wolves** roam in packs and leave you alone, unless you hit one: then the whole pack comes for you. Give a wild wolf a **bone** (right-click it) and it may become yours: it gets a red collar, follows you, and fights whatever attacks you or you attack. At night **zombies**, **skeletons** (they shoot), **creepers** (they hiss, swell and blow a crater), **spiders** (they climb walls; calm by day unless provoked), **slimes** (they bounce, and split into little ones that drop slimeballs) and **witches** (they throw potions) come out and hunt players in Survival; zombies and skeletons burn in the sunlight. **Endermen** turn up at night too: they only fight back, but hit one and it'll teleport right next to you. Hit a mob by clicking it (swords hit harder).
  - **Bows, ender pearls and slime blocks**: craft a **bow** (3 string, 3 sticks) and **arrows** (a feather, a stick and cobblestone; skeletons drop them too), then right-click to shoot the first mob in line up to 32 blocks away. Right-click an **ender pearl** (endermen drop them) to throw it and teleport where it lands. 4 slimeballs make a **slime block**: land on it and you bounce, with no fall damage (hold Shift to land without bouncing). String also makes wool, and chicken and rabbit cook in the furnace recipes. The player who's been in the world longest runs the mobs and shares them through the live room, so everyone sees the same ones; if they leave, the next player takes over where they were.
- **🧱 Bloxverse** (in 🕹️ Games): a Roblox-style hub. Dress up your avatar, then pick an experience and press **▶** to join the busiest server with room, or pick a server from the list. The list can be **sorted** (⭐ Featured, 🔥 Popular: most playing now, ✨ Newest, 🔤 A–Z, 🕒 Recently played), **filtered** by genre (each with how many there are) or to your ❤️ **favourites** (the heart on each card, or on an experience's page), and **searched**; the three newest have a ✨ NEW badge. Your sort, favourites and what you played when are kept on your device. Third-person controls: WASD move (small steps up to 2 studs you just walk up, no jump needed), Space jump, hold **Shift** to sprint (until your stamina, the yellow bar, runs out; the view widens a little as you run), drag to turn the camera (it moves in front of any wall or roof that would hide you), wheel to zoom (all the way in for **first person**: your body's hidden and you see what you're holding), **Ctrl** for **shift lock** (the mouse turns the camera with the pointer locked in the middle, you face where it looks, the camera sits over your right shoulder, and clicks go to the dot in the middle; the menu can swap the keys so Shift is shift lock and Ctrl sprints), **/** to chat (with speech bubbles), **R** to reset your character, **Esc** for the menu. Phones and tablets get a joystick, a jump button, a 🏃 sprint button and a 🔒 shift lock button, and pinch to zoom (all the way in for first person). Games with their own camera (Kart Racing, Mini Golf, Plants vs Zombies, Tower Defense Simulator) leave out shift lock and first person; Zombie Outbreak keeps its own sprint and stamina (on the same key), and +1 Speed Every Step has none. Each server has a live leaderboard, with a small meter under it showing your frames per second and your ping (a tiny message to the server and back, every two seconds; green, yellow or red), which the menu can hide. The sun shines in the sky and casts real shadows; the menu's **🖼️ Graphics** setting picks High (shadows), Low (no shadows and fewer pixels, for slow computers) or Auto (High on a computer, Low on a phone or a computer without a graphics card, and it turns itself down if the frame rate stays under 30 for a few seconds). The home screen features the newest experience at the top, with a Play button.
  - **🏞️ Scenery everywhere** — every experience now sits in its own landscape: rolling hills, a ring of snow-capped mountains, woods of oaks, pines, birches and cherry blossoms, rocks and boulders, bushes, flower patches, ponds with reeds and lily pads, and clouds drifting overhead. Each one has its own look: sky games (Mega Obby, Tower of Hell, Floor is Lava, Red Light Green Light, Color Block) float high above a valley, Tower of Hell above a snowy one under the stars and Floor is Lava above smoking volcanoes; Natural Disaster Survival, Fishing, Steal an Egg and Build a Boat are out at sea with palm-tree islands and sailboats (the boat's river runs through a rocky canyon); Murder Mystery and Blade Ball are at night under a moon, with graves, pumpkins, glowing crystals and fireflies; Hide and Seek is in autumn colours. In +1 Speed Every Step and Pet Simulator the land changes with each zone: meadow, desert with cacti and flat-topped mesas (beach with palms for the pets), snowy peaks with snowmen, volcanoes, candy land with lollipops and candy canes, and outer space with craters, crystals and planets. Games played on the ground get a fence, hedge or stone wall round the edge, so you can't wander off the floor. The scenery is merged into a few big meshes and drawn unlit (its lighting is worked out once), land lost in the fog isn't drawn, and on a slow computer the small things (flowers, bushes, pebbles) are left out.
  - **🎯 Rivals** (new, PvP duels) — a floating lobby with three duel pads (two 1v1, one 2v2): stand on the blue or red side, and when both sides are full (or after six seconds, with 🤖 bots in the empty spots) you're off to one of three arenas: 🏙️ Crossroads (cars, shops and a fountain), ⚓ Dockyard (stacks of shipping containers) or 🏛️ Temple (pillars, ruins and a raised altar). Everyone has 100 health and one life a round; the first team to win **5 rounds** wins the match (the round goes to whoever has more health left if 100 seconds run out). Your **loadout** is a primary, a secondary, a melee and a utility (1–4 to switch, **L** or the 🎒 kiosk to change it in the lobby): Assault Rifle, Burst Rifle, Shotgun, Sniper (hold right-click to scope in; a headshot kills) and Minigun; Handgun, Revolver and Uzi; Fists, Knife (run faster), Katana and Scythe; Grenade, Medkit, Flashbang (blinds anyone looking at it) and Smoke Grenade (nobody sees through it, bots included). The starters are free; the rest unlock with Blox Coins (150–800). Click where to shoot (hold for automatic weapons; **F** fires at the nearest enemy you can see), **R** reloads, **G** throws your utility. Headshots do more; damage numbers and a hit marker show each hit, a kill feed shows who got who, and markers over everyone show their team and health. Out for the round? Watch from the balcony. Try your weapons on the dummies in the practice range. A win pays 15 Blox Coins (6 against bots) plus a coin a kill.
  - **🌻 Plants vs Zombies** (co-op for up to 4) — zombies come off the street and down five lanes of lawn to eat the brains in your house. Collect sun as it falls (click it, or walk into it) and plant seeds on the lawn: pick a seed packet (1–6) and click a tile (hold Shift to plant several). Each packet costs sun and recharges after planting. 🌱 Peashooter, 🌻 Sunflower (more sun), 🍒 Cherry Bomb, 🌰 Wall-nut, 🥔 Potato Mine (arms after a while, then blows up the first zombie to step on it), ❄️ Snow Pea (slows them down), 🌺 Chomper (swallows one whole, then chews for 42 seconds), 🌿 Repeater, 🌶️ Jalapeño (burns a whole lane), 🎃 Squash and ☘️ Threepeater (three lanes). The ⛏️ shovel (X) digs a plant up. Zombies: plain, Flag, Conehead, Pole Vaulting (jumps over your first plant), Buckethead, Newspaper (furious once its paper's gone), Football and the Gargantuar, which smashes plants flat. A lawn mower guards each lane, once; if a zombie gets past a used one, the zombies ate your brains. Ten levels, each ending in a huge wave (the bar along the top shows the waves and 🚩 flags), and each unlocks a new plant; beat level 5 for 🔁 Endless. Before each game everyone votes a level, picks up to six seeds and presses Ready. The sun is shared; each player has their own seed packets. Zombies sometimes drop coins (Blox Coins) and every level pays out.
  - **🙈 Hide and Seek** (new) — a house (living room, bedroom, kitchen, garage, bathroom) and a yard with bushes, trees and a shed. Each round one player seeks: they count with a blindfold on, shut in a box outside, while everyone else hides (inside a wardrobe, the shower, a bush, the shed…; nobody's name shows during the round). Then the door opens: touch a hider to find them, and they seek too (seekers glow red). Find everyone in time and the seekers win; anyone still hidden wins (coins either way). Bots hide, and seek when you're on your own: room to room through the doors, chasing anyone they can see.
  - **🐝 Bee Swarm Simulator** (new) — your bees follow you; walk into a flower field and they fly off to the flowers and bring back pollen (click to collect some yourself with your tool). When your bag is full, make honey on the pad at the hive (E). Honey buys bigger bags (Pouch to Coconut Canister), better tools (Scooper to Super Scooper) and eggs that hatch bees: Basic, Hasty, Brave, Cool (×2 on blue flowers), Rad (×2 on red), Bomber (three flowers at once) and Lion, sometimes ⭐ gifted (double pollen). 5 bees open the 🍀 Clover Field and 10 the 🌹 Rose Field, which pay more. B lists your bees; your hive is saved.
  - **⛳ Mini Golf** — nine holes at your own pace (everyone's out on the course at once, each with their own ball in their shirt colour): Straight Start, The Bend, Sand Trap, The Spinner, Water Hazard, Zig Zag, Uphill, Bumpers and the Grand Finale. Aim with the camera (drag, or A/D); hold the mouse or Space and the power swings up and down; let go to putt. Walls bounce, sand slows the ball, water costs a stroke and puts you back, spinners knock the ball about and the ramp rolls it back. Eight strokes and you pick up. Coins for every hole (most for a hole in one), a scorecard (C), and your best round is saved.
  - **🏎️ Kart Racing** — three laps round a twisty track with a grandstand, kerbs and a minimap; bots fill the grid up to 6 karts. Everyone sits in a kart in their shirt colour. W to go, S to brake (and reverse), A/D to steer; hold Space (or the jump button) while turning at speed to drift, and let go after a moment for a boost (blue sparks, then orange for a bigger one). Orange boost pads speed you up, the grass slows you down, and going way off the track or the wrong way puts you back on it. Lights count down on the start gantry; the banner shows your lap, place and time. Coins for 1st, 2nd, 3rd and finishing, and your best time is saved. H honks.
  - **🚦 Red Light, Green Light** — run up the field while the big robot looks away; when it turns round (red light, the screen glows red) don't move, or you're back at the start. Past the field is the **glass bridge**: eight rows of two glass panels, one of which breaks. Fall and you try again from the start of the bridge — and everyone can see which panels have broken. Everyone who reaches the far side within 2 minutes wins the round (coins, and a win for the first across). Bots join in, and sometimes get caught.
  - **🎨 Color Block** — a floor of coloured tiles over a long drop. A colour is called (it shows in the banner and on the four beacons) and a countdown runs; then every tile that isn't that colour vanishes. Be on the right colour or fall out to the balcony. The floor comes back in a new pattern with more colours, and every call is quicker. A coin for each call you survive; the last one standing wins. Bots join in.
  - **🎣 Fishing** — a lakeside town with four places to fish: 🏞️ Sunny Lake (from the dock), the 🌊 ocean (from the long pier; the deep water past it has rarer fish), a ❄️ frozen pond on top of the snowy hill and a 🌋 lake of lava in a volcano out at sea. Hold the mouse (or the 🎣 Cast button) and let go to cast: the longer you hold, the further it goes. When the bobber dips and a ❗ appears, click to hook the fish, then reel it in: hold to push your green bar right, let go and it drifts left, and keep the fish inside it until the bar fills. 37 kinds of fish from Trash (an old boot) to Mythical (the Kraken, the Phoenix Fish), each with a random weight; heavier and ✨ shiny ones are worth more. Sell your catch at the 💰 Fish Merchant, buy better rods at the 🎣 Rod Shop (each with its own luck, lure speed, bar size and reeling speed; only the Magma Rod and the Rod of the Depths can fish in lava), and fill your 📖 Fish Book (J). Saved; everyone sees each other's rods and lines.
  - **⚔️ Blade Ball** — a glowing ball hunts one player at a time (it turns red and you glow red when it's after you). Parry it with F or a click just before it hits, and it flies off at whoever you're facing, a little faster every time. Press too early and you've whiffed (there's a short cooldown); miss and you're out, watching from the balcony. The last one standing wins. Bots join in so there are always at least four, which also makes it playable on your own.
  - **🔪 Murder Mystery** (2 or more players) — each round one player is secretly the **Murderer**, one the **Sheriff** and the rest **Innocent**, in a mansion with a library, dining room, kitchen, lounge, bedroom and study. The murderer clicks to stab someone close or throws the knife (F or right-click); their knife only shows while it's out. The sheriff shoots where they click (or ahead with F), but shooting an innocent takes them out too. If the sheriff falls their gun drops, and any innocent can grab it and become the hero. Innocents collect coins (Blox Coins) and stay alive; walls stop knives and bullets. The innocents win if the murderer is shot or time runs out (3 minutes); the murderer wins by getting everyone. Out players watch from the lobby above the mansion.
  - **⚡ +1 Speed Every Step** — every second you keep walking you get +1 speed, and the wait for the next gain drops by 10% each time (down to a tenth of a second); stop for more than a moment and it starts again from a second. More speed makes you run faster (up to 240 studs a second; 🐢 L sets a speed limit when you need to be careful). Run the track through six zones (Grassland, Desert, Snowy Peaks, Volcano, Candy Land and Outer Space): each zone's gate opens once you're fast enough (100, 600, 3K, 15K and 80K speed), each finish line pays 🏆 wins and 💵 money, and finishing the whole track sends you back to the hub. Speed orbs on the road give a burst of speed. Three 📜 quests at a time pay money and get harder as you go. 💱 Convert speed into money (10 speed = $1; the speed is taken away). Spend money on six 🥚 eggs whose pets (Common to Legendary) multiply the speed you get every step (a Desert Egg pet is ×1.5 or better; equipped pets add up, 3 slots plus one every 5 rebirths). 🔁 Rebirth gives +1 more speed every step and resets your speed: the first needs 80 speed, the second 100, then 25% more each time. The hub's treadmills keep you walking on the spot: ×2 speed, ×5 from rebirth 3, ×10 from rebirth 10. 🗺️ Teleport to zones you've reached. Saved; everyone sees your pets, and the leaderboard ranks speed.
  - **🧟 Zombie Outbreak** — an open world overrun by zombies: Maple Town (police station, gun store, pharmacy, grocery, diner, chapel and houses), St. Mercy Hospital, a gas station and motel, Sunny Acres Farm, Whispering Woods, Mirror Lake, the Old Graveyard, the Radio Tower and Fort Ironside, the military base, around a walled 🛡️ Safe Zone that zombies can't enter (you heal faster there). Weapons: fists, bat, machete, katana, pistol, revolver, shotgun, SMG, assault rifle, sniper rifle and minigun (1–3 switch melee, sidearm and main gun; click to shoot or swing where you click, hold for automatic weapons, F to fire at the nearest zombie, R to reload, G or right-click for a grenade, H to heal, C to eat, Shift to sprint). Walkers, runners, brutes and exploders, faster and more of them at night; every fourth night is a 🩸 Blood Moon with the Abomination, a giant boss. Watch your ❤️ health, 🍖 food and 🏃 stamina. Kills give XP and cash: level up, buy gear from the 🛒 Trader, get patched up by the ⛑️ Medic, and take on missions from the 📋 board. A minimap, a full 🗺️ map (M) and a 🎒 backpack (B). Dying sends you back to the Safe Zone and costs 10% of your cash; your level, weapons and supplies are saved. Zombies are run by the host; your shots are checked where you fire them.
  - **🥚 Steal an Egg** (up to 8 per server) — eggs ride the red carpet down the middle (25 kinds, Common to Secret, some Gold, Diamond or Rainbow for ×2, ×4 or ×8). Buy one (E) and it hops into your base and earns cash every second; step on the green pad by an egg to collect, or on 💰 Collect all. The 🛍️ Gear shop sells a Speed Coil, a Gravity Coil, a ❄️ Freeze Ray (F), an 👻 Invisibility Cloak (V) and a Golden Bat. ♻️ Rebirth trades your cash and eggs for a permanent earnings boost and more slots. **Replying and editing**: point at a message (or tap it on a phone) and press ↩ to reply or ✏️ to edit one of your own. **Calls (website version)**: open a direct message with someone who's online and press 📞 for a voice call or 🎥 for a video call. You can also use **Call** / **Video** on their profile card. ## Play on claude.ai (no server needed)

The same app also runs as a claude.ai artifact. There, chats and profiles are stored in the artifact's shared database, and live presence and game state travel over the artifact's live rooms. In each game, the challenger's browser runs the game for both players.

- Rebuild it with `node scripts/build-artifact.js`, which writes `dist/game-chat.html`.
- Everyone who uses it needs a claude.ai account. The owner invites each friend by email from the artifact's **Share** menu, as an **Editor**. That's the access level that lets people post, save their profile and play.
- The code lives in `artifact/backend.js`. It stands in for `server.js` and speaks the same message protocol, so the web client runs unchanged.
- The 🤖 AI helper's 🧩 Buddy runs in the page and needs nothing. Its ✨ Claude asks Claude straight from the page (the artifact's `sample` capability), so no API key is needed. Each person's questions use their own Claude plan, and claude.ai asks them to allow it the first time. It also works in the ⧉ popped-out window, which asks through the claude.ai tab (keep that tab open).

## Run it

You need [Node.js](https://nodejs.org) 18 or newer.

```bash
cd chat
npm install
npm start
```

Then open http://localhost:3000. To try it alone, open a second browser (or a private window), make a second account, and chat or play against yourself.

**Playing with friends**
- **Same Wi-Fi**: find your computer's local IP address (for example `192.168.1.20`). Friends open `http://192.168.1.20:3000`.
- **Over the internet**: deploy the `chat` folder to any Node host that supports WebSockets, such as Render, Railway, Fly.io or a VPS. The start command is `npm start`, and the server uses the `PORT` environment variable if it's set.

Accounts, chats and messages are saved to `chat/data/db.json`. Set `DATA_DIR` to store them somewhere else.

### Turn on the AI helper

On the website, the 🤖 AI helper's ✨ Claude questions go through your server to Claude, so the server needs an Anthropic API key:

1. Make a key at [platform.claude.com](https://platform.claude.com) (API keys). Questions are billed to that account.
2. Set it as the `ANTHROPIC_API_KEY` environment variable and restart the server, for example `ANTHROPIC_API_KEY=sk-ant-... npm start`. On Render, add it under your service's **Environment** tab.

Without a key everything else works, 🧩 Buddy included, and choosing ✨ Claude says it isn't switched on yet. The model is set by `AI_MODEL` in `server.js`. If Claude declines a question, Anthropic's server-side fallback retries it on the model Anthropic recommends for that case. To keep costs in check each person can ask up to 30 questions every 15 minutes, one at a time, and only the latest part of a long conversation is sent.

## How it's built

- `server.js`: HTTP server plus WebSocket (`ws`). It handles accounts, rooms, presence, challenges and game sessions. Passwords are hashed with scrypt.
- `shared/rules.js`: chess, checkers, connect four and tic-tac-toe rules. The server uses them to validate every move, and the browser uses them to highlight legal moves.
- `realtime.js`: snake, pong and the fighting game run on the server (server-authoritative), so neither player can cheat. For Tetris, each player's board runs in their own browser and the server passes junk rows between them.
- `public/`: the web client (`index.html`, `style.css`, `app.js` for the chat, `games.js` for the game renderers, `ai.js` for the 🤖 AI helper, `buddy.js` and `buddy-data.js` for its built-in 🧩 Buddy, `tools.js` for the 🧰 Tools).
- `shared/ai-guide.js`: what the AI helper is told about itself and Game Chat. The server's `POST /ai` sends it with each question to Claude (using `@anthropic-ai/sdk`) and streams the answer back.
